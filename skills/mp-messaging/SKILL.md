# Messaging framework (mp-messaging)

Read `../marketing-plan/references/conventions.md` (the shared conventions file in the `marketing-plan` skill, a sibling of this skill's folder) and `references/structure-guide.md` (in this skill's folder) first. Then run the dependency check. This skill needs: 3, 4, 6.

The messaging framework is the reference document for how the brand talks about itself across every channel. It sits on top of positioning. If `06-strategy-activation.md` isn't approved, stop and say so. Messaging built on unsettled positioning has no value.

Write in the brand's voice. Read the project's tone-of-voice or brand guidelines first and follow them, including any banned words or punctuation.

## Inputs

Read these from the plan. Don't re-ask for them:
- The positioning statement, the five answers and the route (06)
- Segments and personas (04). **Inherit these. Don't redefine them.**
- Whitespace and competitors' claims (03), so the messaging doesn't echo a competitor
- Proof: numbers, names, quotes and press from the research pack (01)
- Voice: the brand's tone-of-voice files

If proof is thin, still write the section, then flag it: `[Gap: no {type} proof. Add {specific thing} to make this pillar credible.]`

## Principles

1. **Problem before solution.** From the 100-word version onwards, and in every pillar, open with the audience's situation before introducing the brand.
2. **Progressive disclosure.** The same core message at increasing length. Each version adds new information. A reader can stop at any layer and have something usable.
3. **Proof makes it real.** Named people, specific numbers, direct quotes. A framework is only as strong as its evidence.
4. **Same pillars, different lenses.** Pillars stay constant and get reinterpreted for each persona.
5. **Written to be used, not admired.** Every line can be lifted straight into a page, pitch, caption or brief. Strategic rationale belongs in 06, not here.
6. **Second person, present tense,** unless the brand voice says otherwise.

## Layers

Adapt to complexity. A single-audience brand needs Layers 1–3 plus 5. Add Layer 4 when personas care about meaningfully different things.

1. **Core message at four lengths:** a tagline (3–8 words), one sentence, ~100 words, ~200 words.
2. **Value pillars (3, or 4 at most):** name, then narrative (problem → brand), then proof points.
3. **Differentiators (3, up to 5):** why we deliver the value better than the alternatives. Each has a headline, a short paragraph and evidence.
4. **Persona messaging:** for each persona in `04-icp.md`: a lead message, one sentence, each pillar rewritten for their lens, and the proof that matters to them. Reference the persona by name. Don't copy its profile.
5. **Campaign lines:** 5–10 lines descended from the pillars, each tagged with the pillar it comes from and the motion it suits (Brand / Land / Expand). `mp-tactics` picks these up.

See `references/structure-guide.md` for patterns, examples and word counts.

## Process

1. Draft Layer 1 and ask the user to choose between 2–3 tagline options and approve the one-sentence version before going further. Everything else descends from these.
2. Propose the pillar set (names and one line each), then confirm before writing the narratives.
3. Write the rest of the framework, then run the quality check below.
4. Show the full draft and revise until approved.

## Quality check

Strong:
- Specific to this brand. The tagline wouldn't fit any competitor in 03.
- One strategic thread runs from tagline to campaign lines.
- The pillars don't overlap, and together they cover the value.
- Persona messaging changes the angle, not just the job title.
- Gaps are flagged, not filled with filler.

Weak (fix before showing):
- Generic value ("save time and money", "unforgettable experiences")
- Feature-led or brand-led openings in pillars
- Vague proof ("people love it")
- Anything that reads as strategy or as AI-written
